# Codex Playbook

역할 기반 에이전트 팀을 구성하고 운영 노하우를 축적하는 저장소입니다.

- [역할 목록과 운영 가이드](.codex/agents/README.md): 역할 12개, 업무 배정, 회고, 지침 개선 방법
- [팀 프리셋](.codex/agents/TEAM_PRESETS.md): 버그 수정, 신규 기능, 외부 API 연동, 리팩터링, 성능 개선

## 시작하기

이 저장소를 작업 공간으로 연 뒤 다음처럼 요청합니다.

```text
.codex/agents/TEAM_PRESETS.md의 bugfix 프리셋으로 서브에이전트 팀을 구성해줘.
네가 Compass 역할을 맡아줘.
대상 프로젝트: <작업할 저장소 경로>
태스크: <해결할 문제>
완료 조건: <검증 가능한 결과>
```

다른 프로젝트에서 사용하려면 이 저장소의 역할 파일을 절대 경로로 지정하거나, `.codex/agents/`를 해당 프로젝트로 복사합니다. 기존 파일이 있다면 비교 후 병합합니다. 대상 프로젝트의 지침과 권한을 따릅니다.

## 운영 노하우 반영

개별 역할의 행동은 역할 TOML의 `developer_instructions`에, 팀별 규칙은 `TEAM_PRESETS.md`에 기록합니다. 프로젝트 고유 규칙은 대상 프로젝트의 `AGENTS.md`에서 관리합니다. 회고 근거를 확인한 뒤 적용 조건과 예외를 명시해 규칙을 개선합니다.

이 저장소에는 인증키나 토큰을 저장하지 않습니다. 역할 파일과 프리셋은 재사용할 지침이며 파일을 읽는 것만으로 팀이 자동 실행되지는 않습니다.
